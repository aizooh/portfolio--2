## 🚀 Getting Started Locally (if you want to run or modify it)

To run this portfolio locally:

1. **Clone the repo**

   ```bash
   git clone https://github.com/aizooh/portfolio--2.git
   ```

2. **Change directory**

   ```bash
   cd portfolio--2
   ```

3. Since this is a static site, you can just open `index.html` in your browser, or (for a better local dev experience):

   ```bash
   # Optional: use a simple server
   npx live-server
   # or
   python3 -m http.server 8000
   ```

4. Make edits in HTML / CSS / JS as desired.
